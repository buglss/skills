# Skills / Prompts / Talimatlar

Kendi ihtiyaçlarım için yazdığım `skill/prompt/talimat` metinlerini paylaşıyorum.

`"Türkçe"` olarak yazılmıştır. Bu anlamda globale değil lokale hitap etmektedir.

# Dosyalar ve Kullanım Amaçları

| Dosya | Kullanım amacı |
| --- | --- |

# Değişken Bölümler

Kendime özel yazdığım kısımlar için "{{" karakteri ile başlayan "}}" karakteri ile biten kelimeler kullanıyorum. Bu karakterler arası ("{{" ile başlar "}}" ile kapanır) yazılan kısma siz kendi gerçek bilginizi yazmalısınız.

Bu alanları yapay zeka ile birlikte doldurabilirsiniz. Markdown dosyasını paylaşarak `"Değişken alanları bana sorular sorarak, verdiğim gerçek bilgilere göre doldur. Örnek değerleri bana ait bilgi olarak kabul etme."` talimatını verebilirsiniz.
